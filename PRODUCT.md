# Product

## Platform

web

## Stack

Static HTML5, CSS3, vanilla JavaScript. Hosted via GitHub Pages with custom domain CNAME (`all-in-one-premiums.store`). Integrated with Cloudflare Worker proxy (`x-profile-proxy.evanjawad36.workers.dev` and `x-auto-pilot-backend.evanjawad36.workers.dev`).

## Users

Design-aware digital natives, crypto users, Twitter/X creators, agency operators, and community managers seeking instant access to premium digital subscriptions (X Premium, Telegram Premium) and automation extensions with crypto settlement.

## Product Purpose

All-in-One Premiums provides instant, friction-free activation of verified social and messaging subscriptions paid via cryptocurrency (Binance Pay, USDT BEP20, Solana USDC) without requiring passwords or credential sharing.

## Positioning

Elevated, frictionless subscription delivery and automation tooling with 24-hour verification turnaround, backed by automated Telegram bot order routing and live profile validation.

## Operating Context

Visitors view on mobile and desktop devices. High emphasis on trust, instant proof of safety (non-custodial / no password required), clear copyable crypto addresses, and rapid proof-of-payment submission.

## Capabilities and Constraints

- Capabilities: Instant plan selection, network-specific crypto address copying, live X profile preview verification, screenshot proof upload, automated order payload dispatch via Cloudflare backend to Telegram support.
- Constraints: Single-page static web artifact deployable directly to GitHub Pages root. Zero external client-side build pipeline required unless opted in. Must run reliably without complex runtime overhead.
